# Ben Tinson

That work belongs to the agency, so it isn't here. What's here, or linked from here, is what I build in my own time.

Most of it is live but locked to a handful of email addresses, so the links will show you a sign-in page rather than the app. Happy to walk through any of them.

- [Soletrak](https://app.soletrak.io): sneaker tracking app that blends eBay Browse API asking prices with KicksDB data into a per-pair market value. An LLM assistant that advises on what to buy, wear and sell from wear data, weather and market prices is in progress.
- [Daily Betterments](https://daily-betterments.vercel.app): habit tracker that started as a Claude Artifact and moved to a web app on Supabase and Vercel with Google sign-in.
- [Forge Fitness](https://forge-fitness-psi-two.vercel.app): training app, same setup.
- NBA score model: Python scripts that project scores from pace and offensive and defensive efficiency, backtested on 2025-26 and scored against results every morning this season.
